title: "Detecting Off-Task Behavior from Intelligent Tutoring System Logs"
date: 2026-09-25
category: Educational Data Mining
description: >-
  Built a classifier that flags off-task behavior in field-observed clips of students working in an intelligent tutoring system, where only 4.5% of clips are off-task. Four algorithm families were compared under repeated nested cross-validation grouped by student, so that model and threshold selection never touched the test students. The final gradient boosting model reached a Cohen's Kappa of 0.33 on unseen students, with engineered timing features ranking as its strongest predictors.
